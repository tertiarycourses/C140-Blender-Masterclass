# Lab 6: Rig and animate a looping swim cycle

**Level:** Intermediate

**Alignment:** LO3

## Scenario

The surfaced fish must perform a short, readable swim cycle for stakeholder review.

## Objective

Build a simple armature, validate deformation and animate a clean loop using controlled curves.

## Output

A rigged fish with a looped swim animation and deformation evidence.
